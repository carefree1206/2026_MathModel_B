# 复现指南

## 环境

使用 Python 3.9.13，安装 `requirements.txt`；需要复用本次核验的全部依赖版本时安装 `requirements-lock.txt`。保留在 `支撑材料/环境依赖.txt` 的三项指定依赖与根目录 `requirements.txt` 一致。

严格官方请求重放检查 Python 的完整版本号，因此 3.9.13 不能用其他 3.9 补丁版本替代。原正式测试的运行依赖与指定复现依赖存在差异，历史环境及既有 1171 动作核验记录见 `支撑材料/数据/正式测试/资料说明.md`。

绘图可能因系统中文字体与 Matplotlib 版本产生外观差异。最终 PNG/SVG 已归档，查看论文图无需重新绘图。

## 工程入口

在仓库根目录使用虚拟环境的解释器运行：

```text
python -s -B -X utf8 scripts/reproduce.py --task <任务> [其他原入口参数]
```

| 任务 | 内容 |
| --- | --- |
| `verify` | 源码、参数摘要和 Q3/Q4 正式选型；默认任务 |
| `geometry` | Q1 几何性质、退化情形及覆盖证书 |
| `q2` | 第二测点的上下界重算 |
| `theory` | Q4 点数界、内站条件及圆周覆盖证书 |
| `simulate --problem q3` / `q4` | 新的离线合成单局 |
| `replay` | 12 局既有官方演练的严格请求重放 |
| `stress` | 9 条困难轨迹的严格重放 |
| `benchmark` / `fresh_confirmation` | 原主组、新确认组各 504 次运行 |
| `ablation` | 168 次消融及独立审计 |
| `supplements` | 252 次巡检布局、54 次参数检验及构造检查 |
| `figures` | 从存档数据恢复或重绘论文图件 |
| `all` | 依原顺序执行完整离线复现及一致性检查 |

默认输出为 `results/<任务>_<时间标识>/`。可以指定 `--output results/my_run`；建议每次使用新目录。完整复现结束后检查 `all_checks.json` 的 `passed`。`--help` 直接显示原始入口帮助。

如需沿用原命令，在 `支撑材料/` 中执行 `问题一至四_统一复现.py` 也可；其默认输出仍为原约定的 `支撑材料/运行结果/`，同样已被 Git 忽略。

## GUI、CLI 演示与历史回放

`scripts/launch_demo.py` 启动原交互终端，新结果保存到 `results/gui/`。原机器上的 GUI 新运行曾停在进入场景前，原因未确诊；工程整理没有修改冻结 GUI 或声称修复该问题。

使用 `答辩PPT制作/制作源文件/真实单局回放服务.py` 可以播放已审计记录，服务仅监听本机的 8876、8877 端口，仅支持读取。按 Ctrl+C 停止。对应的事件和截图位置见 `答辩PPT制作/演示运行/现场演示操作提示.md`。

如需生成带逐帧记录的新演示：

```text
python -s -B -X utf8 答辩PPT制作/制作源文件/单局离线演示.py --problem q3
```

新局保存到 `results/demo/`，不会替换 PPT 已引用的原演示。合成单局不计入官方测试或实验均值。

## 官方模拟器

统一复现默认离线。连接官方模拟器需另行在官方程序手动开局，并在原官方入口提供队号、题号及案例码；完整操作沿用 `支撑材料/复现说明.md`。本仓库未保存访问令牌，也没有自动启动正式测试的脚本。
