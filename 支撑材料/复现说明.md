# 支撑材料复现说明

Q3 采用 M020，Q4 采用 M021。模拟终端与命令行共用这两套算法及固定参数；其他策略只作离线对照。

## 文件结构

程序均放在根目录，文件名直接标明题号及用途；全部57个Python程序和1个界面文件在论文附录开头逐项列出。

- **数据/**：中文结果表、固定参数、输入场景、演练与正式日志、证明证书。
- **图件/**：正文16幅插图的PNG、SVG；按正文图号连续编号01—16。正文图4、6、15保留人工修改版，正文图5、14按修订程序重绘。统一入口恢复这5幅定稿PNG并生成同图SVG封装；随包正文图5、14另有原生SVG。来源与恢复方式见`数据/定稿图件/说明.md`。
- **文件清单.json**：全包文件大小与摘要；**数据/程序校验.json**：运行入口必需的源码与参数校验。
- **AI工具使用详情.docx**：AI辅助范围。

## 安装与运行

完整解压后，在本目录打开终端。完整验证环境为 Python 3.9.13、NumPy 1.21.5、SciPy 1.9.1、Matplotlib 3.5.2。六局正式测试的实际运行环境为 Python 3.9.13、NumPy 2.0.2、SciPy 1.13.1；已在前述指定环境严格重放1171个动作，结果一致，见`数据/正式测试/资料说明.md`。

图件的主要生成环境同上；正文图8、9的定稿使用Python 3.11.4、Matplotlib 3.10.7，图5、14也已在该绘图环境独立重绘核对。其他版本可能产生字体或像素差异，数值仍来自相同存档。直接使用随包图件即可查阅，无须为图像字节一致而更换模型计算环境。

```text
python -m pip install -r 环境依赖.txt
python -s -B -X utf8 问题一至四_统一复现.py
python -s -B -X utf8 问题三四_交互模拟终端.py
```

第一条安装依赖；第二条默认只检查源码与参数；第三条打开 Q3/Q4 本机终端，支持离线模拟、官方接口及当前单局回放。`--help`只显示参数。默认输出统一位于本目录的 **运行结果/**，可用原入口参数指定其他输出目录。

完整离线复现：

```text
python -s -B -X utf8 问题一至四_统一复现.py --task all --output 运行结果/完整复现 --workers 6
```

`-s` 排除用户目录中的其他依赖版本，子进程继承此设置。安装需要网络，复现本身不连接官方模拟器。请使用新输出目录，避免与旧结果混合。

完整任务依次重算问题一几何例、问题二上下界、12 局演练响应重放、1008 次策略比较、9 次困难反例重放、168 次消融、252 次巡检布局对照、54 次参数检验、新理论证明，并生成16幅正文图件（其中5幅恢复定稿素材）。性能配置共1482次，涉及340个不同合成世界；复用输入不重复计数。通常需要数分钟至十余分钟。结束后查看 `运行结果/完整复现/all_checks.json` 的 `passed`。

按需运行 `问题一至四_统一复现.py --task <任务名> --output <新目录>`：

- `verify`：源码与固定参数预检，默认任务。
- `geometry`、`q2`：几何性质、连续覆盖、问题二数值界。
- `replay`、`stress`：12局官方演练响应及9条困难轨迹的严格重放；官方严格重放须 Python 3.9.13。六局正式账本另存，不并入这12局。
- `benchmark`、`fresh_confirmation`：原主组、新确认组，各504次运行。
- `ablation`：168次消融及机制关闭核查。
- `supplements`：252次巡检布局、54次参数检验、切向账本及27/21点构造。
- `theory`：19点下界、唯一660米内站、21点二维与圆周证书；仅需标准库，通常数秒至十余秒。
- `figures`：读取存档数值，在指定输出目录的`图件/`中生成正文16幅图件，并恢复5幅定稿PNG及同图SVG位图封装，不重算整场实验；输出使用与正文图号一致的中文文件名，来源见`数据/定稿图件/说明.md`与文件清单。


核验口径：覆盖证书逐格检查定向发现；官方记录按已接受API响应逐动作核对反馈、失败费用及退出条件。异常和期限中断单列；正常完成需已知源全清，并完成其余未知频道确认或已发现16个不同源频道。

理论单项命令：

```text
python -B -X utf8 问题一至四_统一复现.py --task theory --output 运行结果/理论
```

结果见 `运行结果/理论/theory_checks.json`。下界与内站条件共核验960个闭区间；圆周证书核验720个叶区间，并比对实际Q4布局。一般固定发现布局满足19≤N*≤21；一般19、20点可行性仍未确定。完整证明见 `数据/问题四覆盖证明/`。

## 官方接口

默认地址为 `http://127.0.0.1:2026`。由用户在官方模拟器手动开局，核对题号、案例码和队号，再在终端中勾选确认并连接。每局只运行一个算法程序。命令行用法：

```powershell
$env:B_ROBOT_ID = Read-Host '请输入队号'
python -s -B -X utf8 问题三四_官方模拟器连接.py --problem q3 --check
python -s -B -X utf8 问题三四_官方模拟器连接.py --problem q3 --manual-started --test-mode formal --case-code (Read-Host '请输入本局案例码')
```

Q4将`q3`改为`q4`；演练将`formal`改为`practice`。`--check`只作本地检查；`--test-mode formal`仅标记本地记录，不能替代在官方模拟器选择正式测试并手动开局。GUI记录默认保存于`运行结果/模拟器/`，命令行官方记录位于`运行结果/官方/`。结束后核对官方结果页，并按原名导出jlog。不能把未知总源数直接当作全部清除。

## 数据口径与追溯

CSV先算每场总费用/清除数，再对场景等权汇总。P90采用线性插值，上尾均值取最高的`ceil(0.1*n)`场；样本最大值不是数学最坏界。CSV保留原始数值，Excel显示的位数可能较少。

- `数据/benchmark.json.gz`与`paper_evidence.json`：1008行主体对照及统一论文统计；`问题三四_论文统计汇总.py`提供统计入口。
- `数据/stress_rows.json.gz`：546行既有困难实验，其中9条轨迹作严格重放。
- `数据/official_logs/`：本批12局原名jlog；`数据/practice/`为API响应，`practice_results.json`为费用及人工确认。Q3清除86源、Q4清除78源，场景等权均值分别为223.451981、476.890646秒/源。未解密jlog或读取官方隐藏真值，个别案例码的关联依据保留在元数据中。
- `数据/问题三巡检比较/`：三种巡检布局的固定输入及252次结果；`数据/问题三四稳健性/`：54次参数检验、4个结构场景及切向反例原账本。
- `数据/layout_comparison.json`与`数据/layouts/`：27/21点坐标、路径及连续证书；点数和固定路径比较不等于完整清除费用比较。

论文附录列24个完整建模程序及Q3/Q4参数；界面、绘图、独立验证和运行工具完整保存在支撑包中。

六局正式测试已归档到`数据/正式测试/`，含每问三局的官方原名日志、身份记录、原始API账本和中文结果摘要；数值与论文正式结果表对应。`all`与`replay`仍检查既有12局演练，不将正式账本计入1482次性能配置实验。

原始实验JSON保留当时记录的字段与程序标识。历史消融源码压缩副本已在改名时核对原摘要，核对记录见`数据/ablation/原执行源码核对.json`；当前可运行中文程序由`数据/程序校验.json`检查。
