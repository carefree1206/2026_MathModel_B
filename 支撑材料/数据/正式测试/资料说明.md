# 六局正式测试资料

Q3三局采用M020，Q4三局采用M021。`正式结果摘要.csv`可直接查看论文对应数值，`正式结果摘要.json`保留精度、来源与核验说明。

每个`Q题号_次数_测试编码/`目录保存官方原名`.jlog`和`.result.json`，以及中文命名的原始动作、运行摘要、运行清单、运行配置和策略参数。文件内容与原记录逐字节一致；加密jlog未解密。原运行清单中的历史源码路径和摘要是原执行身份记录，当前可运行源码位于支撑材料根目录，不另附重复源码压缩包。

正式身份由官方日志名、result中的题号/次数/编码和日志摘要关联。原本地`test_mode=practice`是旧命令行默认的归档标签，不改变实际官方测试类别，也不改写原字段。

平均耗时为每局虚拟总耗时除以成功清除数；运行时间为官方`/enter`至`/exit`响应的实际时间差。原摘要中的`program_runtime_s`是本地程序计时，二者口径不同。正式总源数和全清比例未提供，摘要JSON保留空值，CSV留空。

正式执行环境为Python 3.9.13、NumPy 2.0.2、SciPy 1.13.1。此前已使用支撑包指定环境Python 3.9.13、NumPy 1.21.5、SciPy 1.9.1、Matplotlib 3.5.2，严格离线重放六局共1171个动作；动作、频道、坐标、虚拟费用和清除结果全部一致。本次整理沿用该证据，没有重新运行测试。

统一入口的`all`和`replay`仍按既有方案重放12局演练。本目录提供六局正式测试与论文对应的原始账本，不纳入原1482次性能配置实验。
