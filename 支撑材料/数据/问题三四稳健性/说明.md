# 局部敏感性与边界压力账本

本目录的实验用于检验正式参数附近的变化，不据此调优默认值。Q3仍采用M020，Q4仍采用M021；均未连接官方模拟器。

## 复现

完整解压支撑材料，保留 `数据/问题三四稳健性/` 目录，使用支撑材料指定的 Python 3.9.13 环境。在支撑材料根目录运行：

```text
python -s -B -X utf8 问题三四_参数敏感性检验.py --output 运行结果/敏感性检验 --workers 1
python -s -B -X utf8 问题四_切向退步案例分析.py --output 运行结果/切向案例分析.json
```

第一个命令执行54次离线求解，输出目录须不存在。实测单进程约82秒，机器负载会影响实际等待时间，不影响虚拟费用口径。第二个命令只按原始逐动作记录重新计算账本和时序，不重跑V12算法。两项均不需要额外依赖。

## 文件

- `cases.json`、`protocol.json`：运行前固定的18个场景和实验方案。
- `问题三四_参数敏感性检验.py`：只改变一个参数的完整离线求解与适用审计。
- `sensitivity_results.json`：54次结果、分组统计、运行记录和完整性检查。
- `run_evidence.json.gz`：54次求解的动作、决策事件与详细审计结果。
- `outer_tangent_v12.json.gz`、`outer_tangent_v14_p2.json.gz`：独立评审保留的同场历史账本。
- `问题四_切向退步案例分析.py`、`outer_tangent_analysis.json`：历史账本复算程序及结果。

## 口径与结论

确认子集：每问按10至16个源分层，各取既有确认组的第00次，共7场。机制压力子集：每问另取10源外缘切向、16源外缘向外两场；Q4同时包含全向和定向源。压力子集使用包内模拟器的误差哈希，**不等同于独立评审跨版本案例的哈希函数**。

Q3仅改变后验光学候选的求积规模 `optical_samples=256/512/1024`，默认512。确认子集的等权每源费用分别为237.40、235.29、236.83秒，平均整场费用分别为3030.72、3006.25、3023.64秒；相对默认最差单场退步分别为4.07%、0、2.64%。两个压力场景的等权每源费用分别为366.11、366.19、366.20秒，最大退步不超过0.01%。规模增大并不保证整场费用单调下降：这里改变的是离散动作排名，而非几何可行域或终止保证。

Q4仅改变已知频道的可选扫描门槛 `scan_gain_m=20/30/40`，默认30米。确认子集等权每源费用分别为454.29、454.41、456.91秒，平均整场费用分别为5749.72、5750.57、5785.48秒；相对默认最差单场退步分别为0.20%、0、5.28%。两个压力场景的等权每源费用分别为586.56、586.38、585.78秒，最大退步不超过0.06%。小面板均值变化有限，但门槛改变仍可能引起离散决策跳变，不能概括为全部参数稳定。

54次运行全部清除，实际计费与适用几何审计通过；其中14次默认参数运行与原确认组的费用、动作数及费用构成一致。14个普通场景沿用已有确认组，不构成新的独立确认组；4个压力场景不能推断官方出现概率。

跨版本案例 `outer_tangent_10_hash`：V12与P2分别为5632.98秒和6866.33秒，均清除10源。增加1233.36秒中，移动占1132.36秒（额外5661.78米），检测占75秒，光学占27秒，切频减少1秒。该案例与M019同组对照分开，不能替代组内均值或最大退步统计。
