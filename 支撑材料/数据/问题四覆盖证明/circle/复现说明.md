# 21点圆周覆盖核验

本目录提供21点布局的独立连续覆盖检查。仅需Python 3.9及以上版本，无第三方依赖，不连接模拟器。

在支撑包根目录运行：

```text
python -B -X utf8 问题四_圆周覆盖证书核验.py --output 运行结果/圆周覆盖核验.json
```

正常结束会显示`passed: true`、`leaves: 720`和`groups: 88`。程序置于支撑包中时，还会自动比对`数据/参数/问题四_算法参数.json`与`数据/q4_coverage_certificate.json`，此时`support_matched: true`。也可通过`--support-root`显式指定包根目录。请勿使用会关闭断言的`python -O`。

## 文件内容

- `问题四_圆周覆盖证书核验.py`：独立核验程序；不导入证书生成器或在线算法。
- `circle_reference21.json`：720个闭参数区间组成的覆盖证书，保留原始字节。
- `圆周覆盖判据.md`：把二维覆盖转化为源边界及接收圆周检查的完整证明。
- `reference_layout.json`：21点整数毫米坐标、Q4配置及原二维证书身份。

核验先确认站位与当前Q4配置对应，再独立展开圆周有理参数的距离与凸包不等式。对每个闭区间检查两端及内部驻点，最后检查全部88组区间完整覆盖。720叶中612叶证明覆盖、108叶完全位于源域内部之外；2148条凸包边和2148条距离约束全部使用精确分数计算。程序另对遗漏区间、错误索引、反向凸包和误用圆心站四种错误证书执行拒绝检查。

本证书使用1000米接收半径；原二维证书保留999.99米的数值余量。两份证书核验同一组毫米坐标。配置中的`cover="ring22"`为沿用的选项名，实际参数为圆心1站、999米内环8站、1867米外环12站，共21站。

此结果验证给定21点布局的连续覆盖；一般19、20点布局的存在性仍未判定。
